# Task Model

A simple PyTorch text model that trains on the provided text corpus and predicts the next token for a given input sequence.

## Files

- `model.py` - training, evaluation, and interactive prediction script
- `train.csv` - training text data
- `validation.csv` - validation text data
- `test.csv` - test text data
- `train.txt` and `test.txt` - raw text inputs used by the project

## Requirements

- Python 3.11+
- PyTorch
- pandas

## Run

```bash
python model.py
```
